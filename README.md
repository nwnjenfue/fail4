# Medeo

Сайт стоматологической клиники в Астане: запись к врачам, кабинеты пациента, врача и администратора, медкарта.
Сервер и база данных написаны на C++17 без внешних библиотек.

## Запуск

Нужен компилятор C++17 (g++ или clang++; на macOS он ставится вместе с Xcode Command Line Tools).

```bash
./run.sh
```

Скрипт сам соберёт `server.cpp` в программу `medeo` и запустит её. Сайт: http://localhost:5180.
Вручную то же самое:

```bash
g++ -O2 -std=c++17 -pthread server.cpp -o medeo && ./medeo
```

При регистрации код подтверждения печатается в терминале, где запущен сервер.

## База данных

При первом открытии сайта создаётся локальный файл `data/medeo.json`. Таблицы: `users`, `doctors`, `appts` (записи), коды подтверждения живут в памяти. Файл базы содержит персональные данные и поэтому исключён из Git; не добавляйте его в публичный репозиторий.
Что проверяет сервер при каждом сохранении (если нарушено — запись отклоняется и ничего не меняется):

- email уникален, роль только `patient`, `doctor` или `admin`;
- у врача на одно время не больше одной активной записи (отменённые не считаются);
- внешние ключи: врач → пользователь, запись → пациент и врач;
- пароли хранятся только хешем PBKDF2-SHA256 (120 000 итераций), код подтверждения живёт 10 минут, пять попыток.

Запись на диск атомарная: сначала временный файл, потом переименование, поэтому при сбое файл не портится.
Чтобы начать с чистого листа, остановите сервер и удалите `data/medeo.json`: демо-данные создадутся заново.

## Состав

- `index.html`, `css/landing.css`, `js/landing.js` — главная страница
- `cabinet.html`, `js/cabinet.js` — личные кабинеты и медкарта
- `js/shared.js` — работа с данными, вход, регистрация с кодом, слоты записи
- `server.cpp` — сервер: раздаёт сайт, хранит базу данных, присылает код в терминал
- `run.sh` — сборка и запуск
- `data/medeo.json` — локальная база данных (создаётся при первом запуске и не публикуется)
